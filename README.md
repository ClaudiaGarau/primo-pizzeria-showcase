# Primo Pizzeria Platform

A full-stack digital hub for a local restaurant: public website, editable menu and internal management experience.

> **Portfolio showcase:** customer information, credentials, environment configuration and production source are intentionally excluded.

## What it demonstrates

- Responsive React and TypeScript frontend
- Supabase database and backend integration
- Editable menu and content-management workflows
- Internal administration experience
- Deployment and iterative product delivery
- Translation of a real business brief into a working digital product

## Development note

The initial product was built with Lovable and subsequently refined through an iterative development workflow. This project is presented separately from work developed primarily with Claude Code.
